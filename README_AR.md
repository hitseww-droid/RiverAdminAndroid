# River Admin — Android MVP

نسخة أولية مستقلة مستوحاة من وظائف ACM لإدارة المجتمعات، بواجهة عربية وألوان داكنة مع الأحمر والذهبي.

## ما يعمل في هذه النسخة
- تطبيق Android مبني بـ Kotlin وJetpack Compose.
- قاعدة بيانات محلية SQLite عبر Room.
- لوحة ملخص وإحصاءات محلية.
- إضافة مجتمعات وحفظها على الجهاز.
- تسجيل البلاغات ومتابعة حالتها.
- شاشة المشرفين وسجل الإجراءات.
- سجل تدقيق للإضافات ومراجعة البلاغات.
- واجهة عربية RTL.

## حدود مهمة
- البيانات الأولية تجريبية وليست بيانات حقيقية من KarboAI.
- لا يوجد اتصال بـ KarboAI ولا API خارجي.
- لا يستطيع التطبيق حظر مستخدمين أو تغيير مجتمعات أو صلاحيات في KarboAI.
- لا توجد بعد حسابات دخول متعددة أو مزامنة سحابية أو تصدير مشفر.
- هذه نسخة MVP وليست جاهزة للاستخدام الإنتاجي.

## بناء APK
1. افتح مجلد المشروع في Android Studio حديث.
2. استخدم JDK 17.
3. وافق على تنزيل Gradle ومكونات Android SDK المطلوبة (Compile SDK 35).
4. من قائمة Build اختر Build APK(s).
5. سيظهر الملف عادة في `app/build/outputs/apk/debug/app-debug.apk`.

يمكن البناء من الطرفية بعد تثبيت Android SDK وGradle:
`gradle assembleDebug`

## الخطوة التالية
إضافة تسجيل دخول محلي، إدارة كاملة للمشرفين والأدوار، تحرير بيانات المجتمعات، البحث والتصفية، ثم نسخ احتياطي وتصدير. قبل تخزين بيانات حقيقية عن المستخدمين، أضف حماية مناسبة وقيود وصول.

## استخراج APK من الهاتف بدون كمبيوتر

> لا يحتوي ملف ZIP نفسه على APK مُجمّع. استخدم GitHub Actions لبنائه على خوادم GitHub:

1. افتح github.com من المتصفح وسجّل الدخول.
2. أنشئ مستودعًا جديدًا باسم `RiverAdmin` واجعله Private إذا كنت تريد إبقاء المصدر خاصًا.
3. فك ضغط `RiverAdminAndroid_MVP_Source.zip`، ثم ارفع **محتويات المجلد** إلى جذر المستودع، مع إبقاء مجلد `.github/workflows` موجودًا.
4. افتح تبويب **Actions** في المستودع واسمح بتشغيل Actions إذا طلب ذلك.
5. اختر **Build River Admin APK** ثم **Run workflow**. ويمكن أن يبدأ البناء تلقائيًا بعد رفع الملفات إلى الفرع `main` أو `master`.
6. افتح عملية البناء الأخيرة بعد أن تنتهي بنجاح، ثم من قسم **Artifacts** نزّل `RiverAdmin-debug-apk`.
7. فك ضغط الملف الذي نزّلته؛ بداخله `app-debug.apk`. افتحه على هاتف Android واسمح بالتثبيت من هذا المصدر عند الطلب.

إذا فشل البناء، افتح سجل العملية وانسخ رسالة الخطأ الأخيرة؛ يمكن استخدامها لتصحيح المشروع.
